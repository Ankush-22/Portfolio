# Ankush Kumar Mallick | Cinematic AI Portfolio

A high-end, modern developer portfolio showcasing expertise in **Machine Learning**, **AI Engineering**, and **Data Science**. Built with a focus on cinematic aesthetics, glassmorphism, and smooth animations.

## 🚀 Live Demo
[Check out the live portfolio here!](https://Ankush-22.github.io/Portfolio/)

## ✨ Key Features
- **Cinematic Hero**: Centered, typographic introduction with dynamic background mesh gradients.
- **AI-Focused Aesthetic**: Custom Purple-to-Blue visual theme designed for the modern AI/ML era.
- **Bento Grid Layout**: Modern, responsive presentation of projects and technical skills.
- **Interactive Tech Stack**: Real-time hover effects and skill progress indicators.
- **Mobile Responsive**: Fully optimized for all screen sizes and devices.
- **Dark/Light Mode**: Premium theme switching with persistent user preference.

## 🛠️ Tech Stack
- **Frontend**: React.js, Tailwind CSS
- **Animations**: GSAP (GreenSock Animation Platform)
- **Styling**: Vanilla CSS (Glassmorphism, Mesh Gradients)
- **Data Science Profile**: Python, TensorFlow, Scikit-learn, Langchain, NLP

## 📁 Project Structure
- `index.html`: Main single-file entry point (optimized for performance).
- `src/components/`: Modular React components for easy maintenance.
- `assets/css/`: Global styles and custom animation configurations.
